# Varnit Kumar's Portfolio

Welcome to the personal portfolio project of **Varnit Kumar**.

## Project Overview

This portfolio showcases my work, skills, and projects as a developer. It is built using modern web technologies for fast performance and a great developer experience.

## Technologies Used

- **Vite** – Fast build tool and development server
- **TypeScript** – Type-safe JavaScript
- **React** – UI library for building interactive interfaces
- **shadcn-ui** – Accessible React components
- **Tailwind CSS** – Utility-first CSS framework

## Getting Started

To run this project locally, follow these steps:

```sh
# 1. Clone the repository
git clone https://github.com/vannu07/varnit-data-folio.git

# 2. Navigate to the project directory
cd varnit-data-folio

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

## Deployment

You can deploy this project using platforms like Vercel, Netlify, or your preferred hosting provider.  
For example, to deploy on Vercel:

1. Push your code to GitHub.
2. Import your repository into [Vercel](https://vercel.com/).
3. Follow the setup instructions.
